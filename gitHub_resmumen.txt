Subir cambios
    # Ver qué ha cambiado
    git status

    # Añadir todos los cambios
    git add .

    # O añadir archivos específicos
    git add asignatura_1/seccion_1/ejercicio_1.py

    # Hacer commit
    git commit -m "Añadido ejercicio de listas y corregido error en funciones"

    # Subir a GitHub
    git push

Bajar cambios
    # Navega a la carpeta de tu proyecto
    cd curso-python

    # Descarga todos los cambios desde GitHub
    git pull

RAMAS
	# Crear rama local pepe que rastree la remota
	git checkout -b pepe origin/pepe

	# O en dos pasos
	git fetch origin
	git checkout pepe

	# Cambiar a la rama pepe
	git checkout pepe

	# O con el comando más nuevo
	git switch pepe
	
	
	# Ver rama actual
	git branch
	# La rama activa tendrá un * al lado

	# Ver todas las ramas (locales y remotas)
	git branch -a
	
	# Ver historial de ramas
	git log --oneline --graph --all --decorate

	SUBIR
	# Si creaste pepe localmente y quieres subirla
	git push origin pepe

	# Configurar upstream para hacer push/pull directo
	git push --set-upstream origin pepe

Merge rama -> main
	1º - Traer cambios de main a mi rama:

	Pasos para actualizar tu rama:

	# Actualiza la rama main: Cambia a main y actualiza con los cambios más recientes del repositorio remoto.
	git checkout main
	git pull

	# Cambia a tu rama: Vuelve a la rama que quieres actualizar.
	git checkout <tu-rama>

	# Fusiona los cambios: Fusiona main en tu rama. Git traerá automáticamente los cambios de main a tu rama actual.
	git merge origin main

	# Resuelve conflictos: Si hay conflictos, Git te lo indicará. Deberás resolverlos manualmente abriendo los archivos marcados y editándolos para integrar los cambios.

	# Confirma la fusión: Una vez que hayas resuelto los conflictos, confirma los cambios.
	git add .
	git commit

	# Actualiza el repositorio remoto (opcional): Si quieres que los cambios de main estén en tu rama en el repositorio remoto, haz un push.
	git push origin <tu-rama>


Merge main -> rama

	# Cambia a la rama main: Muévete a la rama donde quieres incorporar los cambios.
	git checkout main

	# Trae los últimos cambios de main (opcional pero recomendado): Si trabajas con un equipo, es buena idea actualizar main a la última versión remota antes de fusionar.
	git pull origin main

	- Fusiona tu rama: Usa el comando merge para traer todos los cambios de tu rama (ej. mi-rama) a main.
	git merge mi-rama
	
	!!! # si hay un conflicto y quieres deshacer el merge 
		# 1. Cancelar merge en curso
		git merge --abort

	# Resuelve conflictos: Si Git detecta conflictos, tendrás que resolverlos manualmente en los archivos afectados.

	# Confirma y sube los cambios: Una vez que hayas resuelto los conflictos (si los hubo) y estés satisfecho, confirma los cambios y súbelos al repositorio remoto.
	git commit -m "Actualiza main con mis cambios"
	git push origin main

	# Antes de seguir desarrollando recuerda volver a tu rama:
	git checkout mi-rama

Crear rama:
	# 1. Asegúrate de estar en main
	git checkout main

	# 2. Actualiza main desde GitHub
	git pull origin main

	# 3. Crea nueva rama y cámbiate a ella
	git checkout -b nombre-nueva-rama

Consejos útiles:

    git status: Siempre verifica qué archivos han cambiado antes de añadirlos

    git add .: Añade TODOS los archivos modificados

    git add archivo.txt: Añade solo un archivo específico

    Mensajes de commit: Sé descriptivo, por ejemplo:

        "Corregido bug en calculadora"

        "Añadidos ejercicios de bucles"

        "Actualizado README con instrucciones"

============ Conectar PC a GitHub ================================================
==================================================================================

Configurar Git
    git config --global user.name "PeponeDLG"
    git config --global user.email "tu-email@ejemplo.com"

Configurar SSH
    # Generar nueva clave SSH (si no tienes)
    ssh-keygen -t ed25519 -C "tu-email@ejemplo.com"

    # Ver y copiar la clave pública para añadirla en GitHub "settings->SSH and GPG keys"
    cat ~/.ssh/id_ed25519.pub

    # Verificar conexión
    ssh -T git@github.com

Clonar repositorio
    # Navega a donde quieras guardar el proyecto
    cd ~/Documentos  # o donde prefieras

    # Clona el repositorio
    git clone git@github.com:PeponeDLG/curso-python.git

    # Entra en la carpeta
    cd curso-python
